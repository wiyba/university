Практическая работа 1. Введение в С++. Ввод и вывод в консоли
За данную практическую работу баллы не начисляются.
По данной практической работе требуется представить ОТЧЁТ, который надо принести в распечатанном виде на следующую практическую работу.

Предварительное задание (выполняется под руководством преподавателя):

0а. Изучите требования к созданию отчёта по практической работе (информация представлена на странице курса).

0б. Запустите программу Visual Studio и создайте консольное приложение.
Скопируйте на страницу и сохраните код:

#include <iostream>
int main()
{
    setlocale(0,"");
    int age;
    age = 28;
    age++;
    age+=2;
    age=age+3;
    std::cout<<"age="<<age<<std::endl;
    std::getchar(); // данная команда нужна, чтобы выведенная в консоли информация не исчезала сразу по завершении приложения
}
Запустите программу на выполнение. Проверьте, что программа скомпилировалась без ошибок и выполнилась.

С помощью отладки по шагам (кнопка F10) посмотрите в окне отладки, как изменяется значение переменной. Ответьте на вопрос: зачем используется отладка по шагам.

В окне редактора установите точку останова на сером поле на строке age++;. Запустите программу на выполнение обычным способом. Далее используйте кнопку F10. Ответьте на вопрос: когда удобно использовать точку останова?

1а. На сайте metanit.com (https://metanit.com/cpp/tutorial/2.1.php) изучите структуру программы на языке C++.

1б. В консольном приложении создайте переменные разных типов: целочисленную, действительную, булевскую, символьную. Присвойте им значения (присвоение в С++ осуществляется с помощью оператора =). (https://metanit.com/cpp/tutorial/2.3.php)

1в. Изучите информацию о выводе информации в консоль (https://metanit.com/cpp/tutorial/2.10.php). Выведете значения переменных на экран.

1г. Уменьшите значения всех переменных на 1 (элементарные числовые операции во всех языках программирования записываются одинаково). Выведите полученные значения на экран. Поясните полученный результат.

2. Изучите информацию о вводе информации с клавиатуры (https://metanit.com/cpp/tutorial/2.10.php). Введете значения переменных с клавиатуры. Проверьте результат ввода двумя способами: с помощью отладчика по шагам и с помощью вывода информации на экран.

Сформируйте отчёт по практической работе.

Структура отчёта должна быть изучена в процессе выполнения практической работы.
В отчёт следует включить титульный лист, задание, изученную теорию, код и скриншот работы программы задания 1г (с ответами на вопросы), код и скриншот задания 2. Ответы на заданные вопросы предварительного задания следует разместить в разделе отчёта вывод.

Для вывода на экран строковых переменных, значение  которых вводится с клавиатуры, необходимо:
1) подключить модуль windows.h (#include <windows.h>);
2) включить в код строки:
SetConsoleCP(1251); SetConsoleOutputCP(1251);
3) при выполнении программы в консоли в Свойствах выбрать шрифт Lucida Consol.

Без сданного отчёта не будут выставлены баллы за весь модуль!
