Практическая работа 7. Функции

1. Написать функцию, находящую максимум из двух чисел, которые вводятся в main. Вывод максимума осуществить в main.
(Найденный максимум передавать с помощью возвращаемого значения, используя оператор return.) - 1 балл

2. Перегрузить функцию из пункта 1, чтобы можно было находить максимум элементов массива. Ввод количества элементов (не более 20) и самого массива и вывод результата разместить в Main. (Параметрами должны быть и количество элементов, и сам массив, который передаётся по имени.) - 1 балл

3. Написать функцию, в которой вводятся два числа с клавиатуры. В функции main найти и вывести на экран наибольшее из этих чисел.
(Так как надо передать два числа, то следует использовать передачу параметров с помощью ссылки или указателя.) - 1 балл

4. Написать функцию, осуществляющую ввод количества элементов (не более 20) и самого массива. Вернуть в main сам массив и количество его элементов. В main вывести массив на экран. (Возвращаться должны и количество элементов, и сам массив.) - 1 балл

При выполнении работы нельзя инициализировать максимум константой, а также использовать встроенные функции.

В заданиях 1, 3 нельзя использовать массивы, динамическое выделение памяти, векторы и другие контейнеры. 

Задание 2 выполняется после сдачи задания 1.
Задание 4 выполняется после сдачи заданий 2, 3.

Базовыми заданиями являются задания 1, 3.
