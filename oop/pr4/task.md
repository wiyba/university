Практическая работа 4. Циклы

Изучите материал по теме [C++ | Циклы](https://metanit.com/cpp/tutorial/2.13.php).

Выполните задание:

1. С экрана вводится количество чисел и сами числа. Найти наибольшее число и вывести его на экран. Выполнить задание без накопления вводимых данных (без использования массивов, векторов и т.д.). – 1 балл

2. Найти наибольшее число из вводимых с клавиатуры и вывести его на экран. Количество чисел заранее неизвестно (и может быть сколь угодно большим). Числа заканчиваются вводом нуля. Если не введено ни одного числа (сразу введен нуль), то вывести на экран соответствующую информацию. – 1 балл

Для смысловой инициализации наибольшего числа использование констант во всех заданиях запрещено.
Встроенную функцию max использовать нельзя.

В заданиях следует использовать типы циклов, соответствующие условию.

Базовыми заданиями являются задания 1, 2.
